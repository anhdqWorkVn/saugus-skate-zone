Welcome to Saugus Skate Zone

Welcome to Saugus Skate Zone, a sample modern roller-skating rink website for Saugus, Massachusetts. This website is a class project and is not a real business.

Our Purpose

The purpose of this site is to share the fun of roller skating and help visitors learn about the activity. Roller skating can be a fun way to spend time with friends and family.
