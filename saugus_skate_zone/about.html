About This Website

Why I Chose This Topic

My name is Anh Dinh. I created this website for my HTML class. I chose a modern roller-skating rink because skating is an activity that people of different ages can enjoy.

The rink in this project is imaginary. I used Saugus, Massachusetts as the location for the website.

What I Am Learning

In this project, I am practicing HTML pages, links, images, lists, and CSS. I also wanted all five pages to have the same layout so visitors can move between them easily.
